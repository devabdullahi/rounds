Describe the physical exam and vital signs.
- exam.findings: each with the maneuver a student performs, what is found, how often, from which severity, and importance. Include key normal findings that help exclude look-alikes (significance "neutral").
- vitals: value ranges per severity (mild, moderate, severe, critical) in °F, /min, mm Hg and %. Omit a severity or a vital when it stays normal.
- Every exam finding has a "term": its standard clinical name as SNOMED CT names it, one finding only ("Rovsing sign", "Rebound tenderness", "Rales"). Terms name the finding itself and never say "absent", "normal" or "no": an expected-normal check is the finding it rules out ("Rales", "Jugular venous distension") with significance "neutral". "finding" keeps the clinician wording, including that it was absent.
