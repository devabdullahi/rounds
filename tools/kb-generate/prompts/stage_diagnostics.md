Describe labs, ECG, imaging and the workup.
- labs: only tests that are abnormal or decisive. Use test ids from the reference table below, ranges in its units, per severity. Omit severities where the test is normal. Never list derived tests (marked derived); code computes them. For qualitative tests use the "qualitative" map with values from that test's abnormal list.
- ecg: include only when relevant to this condition or its must-not-miss alternatives; otherwise {"findings": []}. Shape: {"findings": [{"feature": "rhythm|rate|axis|p_wave|pr|qrs|qt|st|t_wave|reciprocal|conduction|other", "finding": "text", "frequency": "almost_always|common|sometimes|rare", "leads": ["II", "III"], "min_severity": "moderate"}]}. Put every ECG fact in that list; no other keys.
- imaging: written report findings for each study worth knowing about, including ones that aren't indicated.
- workup.initial/confirmatory/supporting/not_indicated: "test" is a panel id or test id from the table, or an imaging study name. Only orderable tests: not history, exam or vital signs. A test missing from the table goes by its plain name (e.g. "Rapid influenza test"); never make up an id. Each test or study goes in one group. For a test that is not routine but is ordered in some situations, list it in not_indicated AND once in the group it belongs to when ordered, with only_if filled (e.g. chest x-ray: not_indicated, and initial with only_if "pneumonia is suspected"). Use only_if for any other conditional test too.
- workup.scores: ids of standard clinical scores that apply (snake_case, e.g. "wells_pe", "curb_65", "alvarado"). Do not give point values.
